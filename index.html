Cara Install Aplikasi (PWA)

📱 Android (Google Chrome):

Ketuk ikon menu titik tiga (⋮) di pojok kanan atas browser, lalu pilih "Tambahkan ke Layar utama" atau "Install aplikasi".

🍎 iPhone / iPad (Safari):

Ketuk ikon Bagikan (Share) di bagian bawah layar, gulir ke bawah dan pilih "Tambah ke Layar Utama" (Add to Home Screen).

💻 Laptop / PC (Chrome / Edge):

Klik ikon Install (layar dengan panah) di sisi kanan bilah alamat URL browser Anda.
